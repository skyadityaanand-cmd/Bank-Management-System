Project Statement: Bank Account Management System

Problem Statement
The Bank Account Management System addresses the issue where employees calculate financial transactions by hand and make mistakes. In addition students who study software development require realistic examples to learn how computers manage bank balances and transactions. There is a requirement for a simple simulation that performs basic banking tasks without the complicated features of large business software.

Scope of the Project
The project is a Command Line Interface application which I created with Core Java. It operates within the temporary memory of the computer plus the system stores user data and transaction histories in Java Collections like HashMap while the program runs. The software performs necessary tasks like when a user opens an account, adds money, takes money out or checks the balance - but the application does not include permanent data storage in databases or files, visual windows for the user or connections between multiple computers.

Target Users
Computer Science Students & Beginners: Individuals who are learning Core Java, Object-Oriented Programming (OOP) concepts, and data structures.
Educators and Instructors: Teachers looking for a simple, easily readable codebase to demonstrate state management, scanner inputs, and conditional logic.
Individual Developers: Anyone needing to quickly simulate and test simple transaction logic directly from the console.

High-Level Features
1.	Open New Account: Captures user details and an initial deposit to create an account, assigning a uniquely generated account number.
2.	Deposit Funds: Allows users to add money to an existing account via their account number, instantly updating their total balance.
3.	Withdraw Funds: Enables users to deduct money from their account, featuring built-in validation to prevent overdrafts (insufficient funds) and invalid negative entries.
