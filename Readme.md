Bank Account Management System Basic console banking app written in Core Java (OOP and Hash Map learning project) In this project, I wanted to learn: How to get comfortable with Java Object Oriented Programming How to store data in a Java Hash Map No GUI! Just console-based. By the way, I followed this Udemy course while creating this project… Features: Open a new account - your name, initial amount. 

You will get an account number starting from 1001 (auto-increment). 

Deposit Money - based on your account number Withdraw Money - based on your account number. Balance Enquiry - Print the current balance and account holder details Tech stack: Java (Core) Object-Oriented Programming, Scanner, Hash Map, Switch-Case, etc. How to run this project: Make sure you have Java (JDK) installed on your computer. 1. Download / Copy the file named Bank App.java on your local system. 

2. Open terminal / command prompt and change the directory to the folder where you downloaded the file. 

3. Compile java file: 4.

Run java application: Limitations / future scope: It does not save data - it's using Hash Map. So, when you close the console, data will be lost. 

I will add File Input and Output feature (writing/reading to.txt or.csv file) to make the data persistent. Handling input mismatch (e.g. If user enters a letter instead of a number) is not added, which I will do in the future.
